# APMC Mandi Data - Maharashtra

## Overview
This repository contains APMC (Agricultural Produce Market Committee) mandi data for Maharashtra state, India. The data includes market locations, coordinates, and related agricultural market information.

## Data Description
- **File Format:** Excel (.xlsx)
- **Data Period:** updated April 2026
- **Coverage:** All districts in Maharashtra
- **Variables Included:**
  - District Name
  - Market Name
  - Latitude
  - Longitude
 
    
## Data Sources
Data is carefully collected from google maps locations.

## Usage
This data can be used for:
- Spatial analysis of market accessibility
- Agricultural economics research
- Cropping pattern analysis
- Supply chain studies
